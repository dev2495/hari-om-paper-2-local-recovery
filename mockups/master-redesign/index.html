Design system

Why we redesigned both

The current /master/vendors and /master/customers screens treat a relationship master as an HTML form: sparse table, always-open right-rail create panel, contacts wedged at the bottom, no KPIs, no filters, no transactional context. The redesign turns each master into a relationship cockpit.

What changedBeforeAfter
Add formAlways-open right rail (~30% viewport)Modal · opens on demand only
ContactsDetached strip at the bottomNested under the parent row in the drawer
KPI overviewNone4 relationship-specific KPI tiles at the top
FiltersSearch onlySearch · category · status · state · open-orders / overdue-GRN toggle
Transactional contextNot visibleLast GRN, spend, OTIF, quality (vendor) · open orders, AR, OTIF, risk (customer)
Status semanticsUnlabeled power-off iconStatus pill column + bulk activate/deactivate
Bulk operationsNoneMulti-select · CSV import (with preview) · CSV export
Edit flowInline pencil with no obvious saveDrawer with Edit button → form mode → save / cancel footer
